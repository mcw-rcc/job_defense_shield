This alert is generated when jobs show both low CPU utilization and low memory utilization. In many cases, this indicates that more CPU cores and memory were requested than the application actually required.

Common causes include:

  - The application is using fewer CPU cores than were requested.
  - The application is using substantially less memory than was requested.
  - Resource requests were based on estimates that were larger than the application's actual requirements.
  - The workload is spending significant time idle or waiting on other processes.
  - An interactive session was allocated but spent significant time idle.
